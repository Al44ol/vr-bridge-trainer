# Заметки для теории: математическая модель (к сдаче предмета и к защите)

## Заметка с лекции (15.10.2026, со слов пользователя)

> Подход определяет метод. Задача — математическое моделирование (волны Герстнера? Номото?). Разбор системы и подсистем. ВКР — больше, чем диплом, меньше, чем кандидатская. Какой математической моделью пользоваться.

**Условие сдачи предмета:** показать математическую модель. Нужно выбрать, о какой модели рассказывать.

Понимание задания: показать не «всё подряд», а одну модель, рассмотренную как модель, по порядку:
- объект и цель моделирования;
- допущения;
- уравнения и их решение;
- параметры и откуда они взяты (идентификация);
- проверка адекватности;
- границы применимости.

И объяснить, почему для этой задачи выбрана именно она: «подход определяет метод». Модель должна быть вписана в систему: тренажёр → подсистемы → место модели среди них.

## Рекомендация

**Основная — модель 1 (Номото) вместе с моделью 2 (идентификация по эталону Mariner).**

Почему:
- **Это ядро темы.** «Модуль навигационного моделирования» — это и есть она. Не придётся объяснять, зачем модель в ВКР.
- **Просто рассказать.** Одно линейное дифференциальное уравнение первого порядка с понятным смыслом. K — поворотливость (установившаяся угловая скорость на единицу руля), T — инерция (за сколько секунд судно «отвечает» на руль). Решение выписывается в одну строку: r(t) = K·δ·(1 − e^(−t/T)).
- **Эффектно.** Есть графики «модель — эталон» (циркуляция, зигзаг 10/10, 20/20) и проверка критериями IMO MSC.137(76) — числа, которые комиссия может сопоставить с нормой. Всё уже лежит в `ThesisData/Trials/` и `ThesisData/Calibration/` (SVG).
- **Полный цикл моделирования:** допущения → уравнение → решение → параметры (безразмерные K', T') → идентификация (оптимизация по эталону) → проверка адекватности → границы применимости. Именно это обычно хотят увидеть.
- **Ответ на «подход определяет метод»** — иерархия моделей движения в проекте:
  - для учебного плавания на ходу (фарватер, расхождение) нужен только курс и ход, поэтому выбрана простая и быстрая модель Номото: шаг 0,2 мкс, вычислительно устойчива;
  - нелинейность при больших перекладках потребовала модель Норрбина;
  - для швартовки нужен дрейф лагом — модель 3 СС (запрос 19).

  Задача определила уровень модели. Это хорошо ложится на «разбор системы и подсистем».

**Запасная или вторая по счёту — модель 9 (многокритериальная оценка).** Закрывает вторую половину темы («сценарная оценка действий»), математически проста. Хорошо показать вместе с CPA/TCPA (модель 7): из CPA/TCPA получается критерий, из критериев — балл.

**Волны Герстнера (модель 4)** — самая зрелищная (видна в шлеме), но для этой ВКР вспомогательная: это подсистема внешней среды, а не тема. На вопрос «почему Герстнер, а не спектр JONSWAP / Пирсона — Московица» придётся отвечать про компромисс «реализм — производительность в VR при 90 Гц». Годится как пример выбора метода под ограничение (подход определяет метод), но не как главная модель.

**Модель 3 СС и швартовку (модели 3, 12)** для экзамена не советую: много коэффициентов и допущений, рассказ длинный, вопросы трудные. Это материал для главы ВКР, а не для 10-минутного ответа.

## План рассказа (≈ 10 минут) — модель Номото

1. **Система и подсистемы (1 мин).** VR-тренажёр мостика → модуль навигационного моделирования (движение своего судна, среда, другие суда) + модуль сценарной оценки. Место модели — подсистема «движение своего судна». Схема: органы управления (штурвал, телеграф) → рулевая машина → модель движения → положение и курс → сцена, оценка, запись.
2. **Объект, цель и допущения (1 мин).** Водоизмещающее судно на тихой воде, учебные манёвры на ходу. Допущения: рыскание и продольная скорость независимы; нет дрейфа; линейный отклик на руль; ход по закону первого порядка.
3. **Уравнения (2 мин).**
   - Рулевая машина: δ̇ ≤ ω_δ (СОЛАС II-1/29).
   - Ход: du/dt = (u_зад − u)/τ.
   - Рыскание: T·ṙ + r = K·δ, K = K'·U/L, T = T'·L/U.
   - Кинематика: ψ̇ = r; Ė = u·sin ψ, Ṅ = u·cos ψ.
4. **Решение и реализация (1 мин).** Точное решение на шаге dt: r(t+dt) = K·δ + (r − K·δ)·e^(−dt/T). Устойчиво при любом шаге, шаг FixedUpdate 0,02 с.
5. **Параметры и идентификация (2 мин).** K', T' — безразмерные. Эталон — модель Mariner (ПМУ, Chislett & Strøm-Tejsen 1965, MSS). Подбор минимизацией ошибки повтора манёвров (Нелдер–Мид). При большой перекладке нужна нелинейность — модель Норрбина α·r³.
6. **Проверка адекватности (2 мин).** Графики «модель — эталон» (циркуляция 35°, зигзаги) и таблица критериев IMO (выдвиг, тактический диаметр, углы зарыскивания) — табл. 2.x, 3.x ThesisNotes.
7. **Границы применимости и развитие (1 мин).** Нет дрейфа, поэтому для малых скоростей и швартовки модель 3 СС (разд. 19). Иерархия моделей и есть ответ на «подход определяет метод».
