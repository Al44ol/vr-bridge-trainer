## Часть Б. Задание для Claude (новый чат)

### Б.1. Поиск данных (до плана)
Найти в интернете **сухогруз** с опубликованными манёвренными характеристиками. Требования:
- Источник цитируемый: статья, отчёт конференции (SIMMAN, ITTC, MARSIM), учебник, официальный буклет манёвренности (IMO Res. A.601(15)) или формуляр. Для каждого числа — ссылка (автор, год, название, страница/таблица, URL).
- Нужны: L (Lpp), B, T, водоизмещение/Cb, V эксплуатационная; циркуляция 35° (выдвиг, тактический диаметр, по возможности — время 90/180° и скорость на циркуляции); зигзаги 10/10 и 20/20 (углы зарыскивания); торможение (crash stop: путь, время); по возможности — разгон, пассивное торможение, скорости по позициям телеграфа.
- Указать: натурные это данные или модельные (масштаб, свободноходная модель), при какой скорости и осадке.
- **Ни одного выдуманного числа.** Если характеристика не найдена — так и написать; заглушки помечать отдельно.

Кандидаты для проверки (**не проверены, данные искать заново**):
- **Mariner class cargo ship** — классический сухогруз (Chislett, Strøm-Tejsen, 1965; используется в Fossen, «Handbook of Marine Craft Hydrodynamics and Motion Control», модель `mariner`). L ≈ 161 м, ~15 уз — проверить по источнику.
- **KCS** (KRISO Container Ship) — SIMMAN 2008/2014, свободноходные модельные испытания (циркуляция 35°, зигзаги 10/10, 20/20).
- **Series 60** (Cb 0.6–0.7) — серия корпусов сухогрузного типа, много публикаций.
- Российские/советские типовые сухогрузы (например, буклеты/формуляры манёвренности в открытом доступе) — если найдутся с полным набором испытаний.

Представить пользователю таблицу: судно | тип | L, B, T, V | какие испытания есть | натурные/модельные | источник. Ждать выбора.

### Б.2. Калибровка (по Docs/Plan.md, запрос 3)
- Ассет `Assets/Ocean/Settings/ShipParameters_<судно>.asset`; в комментарии/README — источник каждого значения и пометка «заглушка» для недостающих.
- Идентификация K', T' методом выходной ошибки (Нелдер–Мид или сетка с уточнением) на `ShipDynamicsModel` вне Play Mode; эталон — зигзаг (если есть), иначе циркуляция. Параметры скорости — по разгону/торможению.
- Если первый порядок по скорости не попадает в торможение — предложить баланс тяги и сопротивления (du/dt = (T(n) − R(u))/m′, R = c·u|u|), сохранив установившиеся скорости по телеграфу.
- Если линейный Номото не попадает одновременно в 10° и 35° — предложить Норрбина (T·ṙ + r + α·r³ = K·δ).
- Потеря скорости на циркуляции — эмпирическая поправка от r (формула + источник).
- **Не подгонять вручную**: недостижимое — записать как ограничение модели.
- Новые модели — в `VRBridge.Core`, с переключателем «старая/новая», чтобы тест эквивалентности A3.1 и сцена не сломались; новые EditMode-тесты.
