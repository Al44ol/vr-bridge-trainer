# Материалы для ВКР, которых не видно в шлеме

Реестр «закадровых» результатов: таблицы (CSV → Excel), графики и схемы (SVG), отчёты (MD, HTML) и фоновые процессы тренажёра. В гарнитуре их не посмотреть, но они нужны для глав 2–3 и приложений ВКР.
Подробности (формулы, решения, значения) — в `Docs/ThesisNotes.md`, номера разделов и таблиц указаны ниже.

**Правило:** после каждого запроса дописывать сюда новые генераторы, папки и файлы (так же, как раздел в ThesisNotes).

Обозначения: 🖥 — строится в редакторе Unity (пункт меню `Tools/VR Bridge/…`, без Play Mode); 🎮 — пишется само во время работы тренажёра (Play Mode / шлем); 👓 — есть и в шлеме (для сравнения).
Все CSV — разделитель `;`, десятичная точка, UTF-8 с BOM: в Excel открывать через «Данные → Из текста/CSV» или двойным щелчком (если региональные настройки — «;»). SVG открываются в браузере; в Word вставляются как рисунок (Word 365 понимает SVG) или через печать в PDF.

## 2. Что есть только вне шлема

### 2.1. Графики по времени упражнения
- `report.html` каждой сессии: **курс, скорость (с линией безопасной скорости C4), XTE, руль** по времени, отметки вводных D1; журнал событий; таблица критериев; схема SVG. Печатается на A4.
- 👓 В шлеме сейчас — только итог, критерии и схема (вкладки C3). Графики в шлеме — **запрос 17** (Plan.md).

### 2.2. Испытания модели (без Play Mode)
- Циркуляция, зигзаг, торможение, разгон — только в `Trials/`; в шлеме модель видна лишь как поведение судна.
- Калибровка (Нелдер–Мид, этапы `stages/`) — только в `Calibration/`.
- Качка по курсовым углам — только в `Seakeeping/`.

### 2.3. Прогоны «за обучающегося»
`ExerciseSimulation` + `DemoAssessmentRuns` проходят сценарии без человека (правильно / поздно / влево / без манёвра / без сигналов / вводные) — доказательство, что оценка различает действия. Таблицы 10.3, 12.5, 13.1; схемы `*_tracks.svg`.

### 2.4. Сверка «шлем = запись»
Оценка в шлеме и пересчёт по записи совпадают бит в бит (п. 10.10): Session Replay → «Оценка по записи (C2)» → «совпадает с оценкой в шлеме»; в `Debrief/summary.md` — у каждого прогона.

### 2.5. Фоновые процессы тренажёра (для описания архитектуры)
| Процесс | Где | Что делает | ThesisNotes |

## 3. Как получить свежие данные перед написанием главы
1. Unity, без Play Mode: `Tools/VR Bridge/` → Manoeuvring Trials, Model Calibration, Seakeeping Trials, Traffic Report, Assessment Report, Debrief Report — каждый создаёт новую папку с датой (старые не перезаписываются).
2. После эксперимента: `Sessions Summary…` → папка с сессиями → `ThesisData/Summary/<дата>/sessions_summary.csv`.
3. Производительность: в шлеме меню Y → «Замер» в нужных условиях → строка в `frametiming_summary.csv`.
